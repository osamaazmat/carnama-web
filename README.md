# Carnama - Car Management App

Carnama is a modern web application designed to help users manage their vehicles efficiently. The platform provides features for tracking maintenance, managing fuel consumption, and organizing vehicle-related documents.

## Features

- Vehicle Management
- Maintenance Tracking
- Fuel Consumption Monitoring
- Document Management
- Service History
- Cost Tracking

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Vercel (Deployment)

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/carnama-web.git
cd carnama-web
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is configured for easy deployment on Vercel. To deploy:

1. Push your code to a Git repository (GitHub, GitLab, or Bitbucket)
2. Import your repository to Vercel
3. Vercel will automatically detect Next.js and deploy your application
